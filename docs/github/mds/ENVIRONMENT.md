#### ENV file configuration variables

The ``.env`` file is located on this path: ``env/.env``

> [!NOTE]
>
> If you do not modify .env, the devstack will use ``default`` values. Changing those after the .env file is built requires you to run this command ``make rebuild-image name=<service-name>`` command. It will recreate image/container, without changing compose file.

| Service                                                                         | Variable                        | Allowed Values                                                                                 | Description / Note                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
|---------------------------------------------------------------------------------|---------------------------------|:-----------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Use cli<br/> `make mode-{mode}`<br/> It **will rebuild**<br/> `image/container` | `ADOBE_COMMERCE_MODE`           | `developer` (``default``)<br/>  `production`                                                   | Sets the Adobe Commerce mode. If changed manually, you must rebuild Nginx.<br/>  Use: <br/> - `make mode-developer` to set ``developer mode`` <br/> - `make mode-production` to set ``production mode``<br/><br/>  Both command will automatically recreate ``nginx`` service, so no needs to do extra work                                                                                                                                                                                                                  |
| `nginx`                                                                         | `DEVELOPER_MODE_BYPASS_VARNISH` | `"true"`(``default``) <br/> `"false"`                                                          | **``"true"``**: varnish ``is "bypassed"`` (the data ``is NOT taken`` **from cache**, upstream directs to ``php-app`` always) <br>  **``"false"``** : varnish ``is not "bypassed"`` (the data ``is taken`` **from cache**)<br/><br/>  You can set it for both Adobe Commerce modes ``production`` and ``developer``, but keep in mind it will lead you to very strange cache results for ``developer mode``.<br/><br/> **Please, use it only with the**  ``production mode`` **to test cache results and cache-related bugs** |
| `web-app`                                                                       | `NODE_VERSION`                  | `16-alpine`<br/> `17-alpine`<br/> `18-alpine`<br/>  `20-alpine`(``default``)<br/> `{N}-alpine` | Defines the ``node`` version for the `web-app` container.<br/> Changing this var you need the ``NODE_OPTIONS_OPEN_SSL`` has ``node`` version-specific value (see below) as well                                                                                                                                                                                                                                                                                                                                              |
| `web-app`                                                                       | `NODE_OPTIONS_OPEN_SSL`         | `--openssl-legacy-provider`(``default``) <br/>  or *empty*                                     | ``node >= 17``:<br/> - ``NODE_OPTIONS_OPEN_SSL=--openssl-legacy-provider`` <br/>``node < 17``:<br/> - ``NODE_OPTIONS_OPEN_SSL=``<a id="node-option-open-ssl"></a>                                                                                                                                                                                                                                                                                                                                                            |
| `php-app`                                                                       | `XDEBUG_ENABLED`                | `true` (``default``) <br/> `false`                                                             | Enables or disables the Xdebug                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
